# Catastro PWA - Loyalty por producto 18.0.1.0.2

Add-on opcional para Odoo 18. Necesita `conedera_odoo_census_mobile` y `sale_loyalty`.
Aplica solo promociones automáticas porcentuales sobre productos específicos en
`sale.order.line.discount`, con revalidación de reglas nativas al guardar/confirmar.
No sustituye cupones, monederos ni recompensas que consuman puntos.
Consulte `ACTUALIZACION_18.0.1.5.19.md` en el complemento PWA para instalación,
HTTPS, PDF e instrucciones de aceptación.
